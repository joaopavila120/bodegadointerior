Create FOUR full-body SIDE PROFILE walking frames, all facing RIGHT, in ONE horizontal row of FOUR evenly spaced cells. Same body height, proportions, face, clothing, overhead 3/4 RPG camera with visible tops of shoulders and boots. Frame1 left foot forward contact; frame2 feet close passing pose; frame3 right foot forward contact; frame4 opposite passing pose. Arms naturally counter-swing. Each figure fully inside own cell with generous transparent separation, same ground baseline. Restrained detailed pixel art with crisp clusters and dark pixel outlines matching reference, not photorealistic. No scenery, no shadows, no lettering, no grids, no other characters. Genuine transparent alpha background. Output wide landscape sprite sheet.
